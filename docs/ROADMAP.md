# Roadmap (planned, not built)

## Next: Home redesign and smooth motion

**Home (All notes, Pinned)**
- No top app bar. A rounded, outlined search bar at the top with the menu icon inside it (placeholder "Search in Notes"). No login row (the app has no accounts).
- Section header rows with the section name in the accent color: **PINNED** first, then **RECENT**; Sort and List/Grid icons sit on the right of the first header row.
- Empty state like the reference: a "TIP" chip, a short tip, and a "Create a new note →" button. Tips rotate and describe real features (pin, tags, folders, checklists, tables).

**Folders and tag views**
- A top bar returns with the folder or tag name and action icons: Search, List/Grid, Sort, and a 3-dot menu (Rename, Delete) for folders.

**Note rows (list layout, as in the reference)**
- Time, bold title, preview, tag chips with a pin icon, a left accent bar for pinned or colored notes, thin dividers between rows, and a 3-dot menu (Pin, Move to folder, Add tag, Trash).
- Grid layout: the same content as cards (time, title, preview, tags, pin, accent edge, 3-dot menu), staggered, with the same spacing and radius.

**Motion**
- Smooth animation across the app: menu slide (already pushes the notes), list scrolling (smooth fling, item add/remove/reorder animations, list/grid switch), pin/section changes, screen transitions, dialogs and sheets.
- Honor the system "remove animations" setting.
